## 修复 SUATCatManager.exe 无法使用

- 现象：双击 exe 打开的窗口空白/无法使用。
- 根因：近期把数据文件重构进 `data/` 目录时，误删了 `app_manager.html`（管理器前端）。而 `app.py` 的内置 HTTP 服务器仍在 `BASE_DIR` 根目录提供 `/app_manager.html`，导致 exe 运行时该页面 404。
- 关键点：`app_manager.html` 是通过磁盘上的 HTTP 服务器提供的，**并未被 PyInstaller 打进 exe**（build.py 没有 --add-data 该 html）。因此只需把文件放回项目根目录即可修复现有 exe，**无需重新打包**。
- 该前端所有数据均通过 pywebview `js_api`（`api.*`）获取，不直接 fetch json，因此与新的 `data/` 结构完全兼容，无需改内部路径；它只静态引用根目录的 `marked.min.js`（存在）。
- 修复：恢复 `app_manager.html` 到项目根目录（79993 字节）。
- 验证：用与 app.py 相同逻辑的临时 HTTP 服务器测试，`/app_manager.html`、`/marked.min.js`、`/data/cats.json`、`/index.html` 均返回 200。

## 项目架构备忘
- 公开站：`index.html` → 按设备跳转 `data/index_pc.html` / `data/index_mobile.html`。
- 管理器（exe）：`app.py`(后端 + 本地 HTTP + pywebview) + `app_manager.html`(前端)。
- exe 运行时数据/前端均从磁盘读取（exe 同目录），故这些文件必须与 exe 同目录，不能删。
